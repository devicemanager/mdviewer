# MDViewer Keyboard Shortcuts

A quick reference for all keyboard shortcuts in MDViewer.

## File Operations

| Shortcut | Action |
|----------|--------|
| **⌘O** | Open file |
| **⌘W** | Close current window |
| **⌘T** | Open new tab |
| **⌘N** | New window |
| **⌘S** | Save (editor mode only) |
| **⌘R** | Reload current file |

## Viewing & Navigation

| Shortcut | Action |
|----------|--------|
| **⌘F** | Find text (search bar) |
| **⌘E** | Toggle editor mode |
| **⌘Shift+S** | Toggle sidebar visibility |
| **Space/Shift+Space** | Jump to next/previous search result |
| **Escape** | Close search bar |

## Text Zoom

| Shortcut | Action |
|----------|--------|
| **⌘+** | Increase font size |
| **⌘-** | Decrease font size |
| **⌘0** | Reset font size to default (14pt) |

## Export & Print

| Shortcut | Action |
|----------|--------|
| **⌘P** | Print |
| **⌘Shift+P** | Export to PDF |
| **⌘Shift+E** | Export to HTML |

## Editor Mode (when enabled with ⌘E)

| Shortcut | Action |
|----------|--------|
| **⌘S** | Save changes |
| **⌘Z** | Undo |
| **⌘Shift+Z** | Redo |
| **⌘A** | Select all |
| **⌘C** | Copy |
| **⌘X** | Cut |
| **⌘V** | Paste |

## macOS Standard Shortcuts

These work throughout MDViewer:

| Shortcut | Action |
|----------|--------|
| **⌘Q** | Quit MDViewer |
| **⌘,** | Open Preferences |
| **⌘M** | Minimize window |
| **⌘H** | Hide MDViewer |
| **⌘Tab** | Switch between apps |

---

## Tips

- All shortcuts use the **⌘ Command** key (not Control)
- Shortcuts are case-sensitive (⌘Shift means Command + Shift)
- Zoom level (font size) is saved between sessions
- Search highlights persist until you close the search bar
- Editor mode changes aren't saved until you press ⌘S

For more information, see [Features](features.md) and [Getting Started](getting-started.md).
